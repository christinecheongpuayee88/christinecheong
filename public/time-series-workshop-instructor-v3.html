AI-generated cohort reports

Run once per stage, after closing that stage's quiz window. Each report compares this cohort against every report before it, then appends itself to the Cohort Intelligence Log for the next stage to read. Every stage closes with a "Top Teaching Moves" section — up to 3 recommendations in a 🔴 Clarify / 🟢 Apply / 🔵 Challenge framework, each naming a specific micro-intervention move (see the Micro-Interventions Library ↗ for how to run each one) alongside the theory recap slide or matching workshop exercise. If you've graded assignments via the Assignments tab first (same page load), the Final Report also gets a rubric-informed section appended after that, backed by actual graded work.
