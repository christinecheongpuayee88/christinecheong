From Templates to Tool Stack

Tools should be selected based on the decision task, not introduced all at once. Start with the essential tool for each template — reach for the advanced tool or agent only once the basic workflow feels natural.

TemplateStarting ToolAdvanced Tool / Skill
1. Decision FramingChatContext files, Product Discovery Agent
2. Situation AssessmentChat + uploaded evidenceDeep Research, NotebookLM, Research Briefing Agent
3. Root Cause AnalysisProjectData Insight Agent, Behavioural Science Agent
4. Evidence ValidationNotebookLM / visualsImperial AI Council, Data Insight Agent
5. Options AssessmentChat + scoring tableCustom GPT, Claude Skill, Proposal Pitch Agent
6. Executive Action PlanChat + action tableAgent Mode, Planning Task Management Agent

Do not start with agents. Start with better decision thinking, then choose the right tool.
